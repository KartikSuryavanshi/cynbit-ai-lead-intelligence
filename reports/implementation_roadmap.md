# Implementation Roadmap

## Phase 1 — PoC (complete)

Acceptance: local demo launches without credentials; form and CSV create validated records; dashboard shows counts/charts; drafts are editable; tests pass.

## Phase 2 — Discovery pilot (2–3 weeks)

Confirm service taxonomy, redact/obtain consent for representative enquiries, define reviewer rubric, and baseline response-time and completeness KPIs.

## Phase 3 — Controlled integration (3–5 weeks)

Add authenticated CRM read/write behind approval, role-based access, audit logs, retention controls, provider retries, and a reviewer feedback loop.

## Phase 4 — Evaluation and hardening (2–4 weeks)

Measure extraction accuracy, priority agreement, edit rate, latency, cost, and unsafe-output rate against a labelled set; conduct privacy/security review and release-gate testing.
